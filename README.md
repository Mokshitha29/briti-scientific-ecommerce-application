# Chemical E-Commerce Platform

A full-stack chemical e-commerce web application developed using the **MEAN stack (MongoDB, Express.js, Angular, and Node.js)**. The platform allows users to browse chemical products, view product details, select different pack sizes, manage their shopping cart, place orders, and make demo payments.

The application also includes secure user authentication, role-based access for **Users and Admins**, product and category management, order management, customer enquiries, contact messages, and an admin dashboard for managing the platform.
